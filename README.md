# Transit Pulse

Предиктор изменений в графике движения городского транспорта (хакатон Московского транспорта).

Система принимает поток телеметрии NDTP, сопоставляет его с расписанием, за 10–15 минут
прогнозирует задержку ТС на остановке и показывает алерты на дашборде диспетчера.

> Репозиторий в активной разработке. Инструкция по запуску в Docker появится здесь.

## Разработка

```bash
uv sync            # окружение Python (3.12+)
uv run pytest      # тесты
uv run ruff check  # линтер
```

Датасет организаторов в репозиторий не входит: положите архив в `./data/`.
