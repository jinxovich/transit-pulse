загрузок в сутки. Score на validate: `(mae0 − MAE) / (mae0 − MAE_T)`; по нашей оценке
mae0 ≈ 108.1, baseline `cur_dev_s` ≈ 88.7, MAE_T ≈ 59.6, то есть score 0.7 ↔ MAE ≈ 74.
