app.inference¶

Инференс без веб-обвязки: загрузка моделей, квантили, p_late, вклады признаков.

Модель предсказывает остаток delay − cur_dev квантилями 0.1/0.5/0.9. Абсолютный прогноз = cur_dev (NaN → 0) + квантиль; q10/q90 растянуты от медианы множителем interval_scale из калибровки (покрытие 80% на OOF). Если рядом с моделью лежит calibration_{mode}.json (services.ml.app.calibration), масштаб берётся по корзине признака lead, а p_late проходит изотоническую калибровку. Вклад cur_dev в ответе включает саму базу, так что сумма вкладов по всем признакам + expected_value = delay_s.
