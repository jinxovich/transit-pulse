app¶

ML-сервис Transit Pulse: модели прогноза задержки (обучение и артефакты).

Modules

calibration

Калибровка прогноза по OOF: интервалы по корзинам lead и изотоника для p_late.

cv

Повторяемый GroupKFold (3×5) по (tr_id, 30-мин блок) на реальных размеченных точках.

dataset

Сборка обучающих таблиц через тот же transit_core.features.point_features().

ensemble

Ансамбль для сабмита: веса CatBoost / LightGBM / GRU / LightGBM-v1 по OOF на общих фолдах.

inference

Инференс без веб-обвязки: загрузка моделей, квантили, p_late, вклады признаков.

models

Обёртки моделей: CatBoost MultiQuantile (основная) и LightGBM L1 (сравнение, бленд).

openapi_examples

Примеры тела POST /predict для Swagger «Try it out».

seq_data

Сборка выборки для GRU: треки из CSV, плановое расписание, тензоры на точки прогноза.

seq_model

GRU-модель остатка задержки: последовательность телеметрии + статика группы A.

seq_onnx

Экспорт GRU-ансамбля в ONNX, проверка паритета и замер латентности onnxruntime.

serve

ML-сервис Transit Pulse (FastAPI, порт 8001): батч-прогноз задержки по признакам as-of T.

train

Обучение v2: CV (baseline / LightGBM v1 / CatBoost), выбор веса синтетики, финальные модели.

v1_compare

LightGBM v1 (scripts/quick_v1.py: его признаки и параметры) на тех же фолдах, что v2.
