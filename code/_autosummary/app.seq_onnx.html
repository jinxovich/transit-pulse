app.seq_onnx¶

Экспорт GRU-ансамбля в ONNX, проверка паритета и замер латентности onnxruntime.

Граф на выходе отдаёт абсолютную задержку в секундах: delay_s = cur_dev_s + среднее остатков по моделям, где cur_dev_s восстанавливается из первого статического признака (static[:, 0] · CUR_DEV_SCALE). Сервингу нужен только onnxruntime и функции build_sequence/sequence_static.
