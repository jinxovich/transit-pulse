transit_core.route_line¶

Нитка рейса: полилиния по плановым остановкам и проекция точки на неё.

Нитка строится по остановкам одного рейса плана (trip из transit_core.plan.load_plan()) в локальных метрах (transit_core.track.to_xy()). Для каждой остановки известны накопленная дистанция по нитке и плановое время — отсюда плановое время любой точки нитки (линейная интерполяция между соседними остановками).

planned_at(s, t)[исходный код]¶

Плановое время прохождения точки s нитки с учётом стоянок.

Между остановками — линейная интерполяция плановых времён. Если s ровно на остановке (или на нескольких совпадающих), план — окно [tb_первой, tb_последней]: ожидание внутри окна не считается отклонением. До отправления с первой остановки рейса (отстой на конечной) ТС не опаздывает, пока плановое время не наступило.

Параметры:

  • s (float)

  • t (float)
